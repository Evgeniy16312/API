# Продажи и маркетинговый сайт

## Кому продаём (порядок, не «всем»)

1. **Кондитеры / торты, цветы, фототорты** — мало заказов, высокая цена заказа, боль блокнота. Канал: чаты кондитеров, Avito «торты на заказ», сарафан.
2. **Домашний маникюр / брови** — много переписок. Канал: VK-сообщества мастеров города, Telegram «мастера [город]».
3. **Аренда кресла** — уже платят за место, 249 ₽ не вопрос. Канал: барбер-чаты, личный обход знакомых.
4. Не в первую очередь: сети салонов, госзакупки, франшизы.

Гео: город пилота + соседние. Не «вся Россия» в Директе в месяц 1.

## Как продаём (дешёвые каналы → дорогие)

| Неделя | Действие | Зачем |
|--------|----------|--------|
| Каждую | 10–20 личных сообщений мастерам с живым Instagram/VK | конверсия 5–15%, обучение офферу |
| 1–4 | Лендинг F39 + QR на визитке владельца | без сайта продавать стыдно |
| 1–8 | Посты в 5 чатах ниши (не спам: «сам пользуюсь, вот ссылка») | доверие |
| 4+ | Avito: услуга «сайт записи для мастера» как лидген | мастера ищут «запись онлайн» |
| 8+ | SEO: «онлайн запись для кондитера», «для мастера маникюра» — не «CRM салон» (там YCLIENTS) | долгий хвост |
| Позже | Директ только на бренд + нишевые минус-слова yclients | иначе сжигаем бюджет |

Не покупать трафик «запись в салон» пока нет кейсов.

## Сайт с рекламой сервиса (F39)

Сейчас `/` — короткий лендинг в PWA. Нужна **продающая витрина**, не кабинет:

- Блок проблемы (чат vs слот)
- 3 шага
- 3 тарифа (99/249/499) с «мало заказов → Старт»
- Сравнение: 0% комиссии vs агрегатор
- Живой пример `/m/пилот`
- FAQ: «зачем если есть WhatsApp», «чем хуже Dikidi бесплатно»
- Юр. мелочи: оферта, контакты, реквизиты когда будет самозанятость
- CTA sticky на мобиле (уже паттерн F37)

Отдельный домен не нужен: `myazapis.ru` = сайт. `/app` = продукт. Не плодить Tilda, если не хотим два места правки — лучше страницы в этом же Next.

## План 90 дней (продажи)

| День | Цель |
|------|------|
| 0–14 | 5 платящих знакомых / пилот, снять 3 скрина кейса |
| 15–45 | 30 регистраций/нед. из чатов, конверсия trial→pay > 20% |
| 46–90 | 50–80 платящих, понять микс lite/basic/pro, включить год |

Метрики в админке (потом): регистрации, % дошли до первой услуги, % отправили ссылку (прокси: есть booking), % оплатили.
