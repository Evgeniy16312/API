## Снимок решений (2026-08-14)

- Целевой клиент: **частный мастер с телефона**, не салон на 10 кресел.
- Главный конкурент дешёвого края: **блокнот + WhatsApp**, не YCLIENTS.
- Главный конкурент «уже пользуюсь»: **Dikidi (часто «бесплатно» + комиссия агрегатора)**.
- Клин: **своя ссылка, 0% с записи, запуск за 2 минуты, 149 ₽ если заказов мало**.
- Pro-фишка витрины: свой дизайн страницы (F38).
- 1000 мастеров: инфра **~3–5 тыс. ₽/мес**, не сотни тысяч. Упираемся в продукт и продажи, не в железо.
