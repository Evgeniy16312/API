# Roadmap продукта «МояЗапись»

Целевой сценарий: мастер регистрируется → даёт ссылку/QR → клиент смотрит портфолио, услуги, прайс и записывается → мастер получает уведомление в **MAX** / **VK**.

## Где мы сейчас

| Функция | Статус |
|---------|--------|
| Регистрация, панель, услуги, календарь, карта | ✅ |
| Публичная запись + QR | ✅ |
| Auth cookie + код доступа | ✅ |
| Outbox уведомлений + retry | ✅ (F19) |
| MAX кнопки подтвердить/отменить | ✅ (F20) |
| Напоминания мастеру 24ч/2ч | ✅ (F13) |
| VK connect-коды + callback | 🔄 нужен Callback в кабинете VK |
| Портфолио/аватар на диск | ✅ |
| SEO публичной страницы | ✅ |
| Деплой Docker-файлы | ✅ код готов |
| Деплой на ваш VPS + HTTPS | 🔄 VPS жив; домен myazapis.ru ждёт DNS TLD |
| MAX webhook в проде | ⏳ нужен HTTPS на домене |
| Оплата / тарифы | ❌ Фаза 4 |

## Фазы

### Фаза 1 — пилот (стоп: нужен ваш VPS)
1.1–1.2 Docker + домен + SSL — **инструкции готовы** (`docs/deploy.md`)  
1.3–1.5 MAX в проде + пилот — **после вашего домена**

### Фаза 2 — стабильность уведомлений ✅ код
Outbox, MAX-кнопки, напоминания, VK connect (настройка на сервере).

### Фаза 3 — полировка ✅ частично
Аватар, SEO, контакты, карта, календарь. Отзывы — позже.

### Фаза 4–5
Тарифы, салон, каталог — не начинаем до пилота.
