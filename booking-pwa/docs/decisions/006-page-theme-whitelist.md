# 006 — Тема публичной страницы только whitelist, не CSS

## Context

Мастеру на Pro нужна «своя» витрина. Произвольный CSS/HTML в теме — XSS и сломанная запись на телефоне клиента.

## Decision

Хранить JSON (`accent`, `background`, `ink`, `header`, `card`, `font`) с HEX `#rrggbb` и шрифтами из белого списка. Применять через CSS variables на `/m/[slug]`. Basic и trial всегда отдают классическую тему, сохранённый JSON не удаляем при даунгрейде.

## Consequences

Нельзя загрузить свой webfont или править отступы пиксельно. Новые поля темы — отдельная итерация. Кабинет `/app` остаётся классическим.
