# 007 — Три тарифа: Старт / Мастер / Витрина

## Context

Сейчас в коде два платных плана (290 / 590). Часть рынка (кондитеры, 1–2 заказа/день) сравнивает продукт с блокнотом и не берёт «как CRM». Нужен третий дешёвый край, не ломая Pro-дизайн витрины.

## Decision

Ввести `lite` = 149 ₽ (ссылка + слоты + email, без напоминаний и без темы). Basic 290 = напоминания. Pro 590 = тема страницы. Не лимитировать число записей на Lite. Подробности: `docs/business/pricing.md`. В коде — F40 (`lite` / `basic` / `pro`).

## Consequences

Больше карточек на `/app/billing`, feature flags по плану, админка знает `lite`. Риск каннибализации Basic → смягчается trial «как Мастер» и явной таблицей «что получите за 290».
