# ADR 002 — Уведомления через MAX и VK, не Telegram

## Статус

Superseded by [005-telegram-channel.md](./005-telegram-channel.md)

## Контекст

Telegram в РФ часто недоступен без VPN. Изначально исключили канал.

## Решение (историческое)

Каналы: MAX и VK; Telegram не интегрировать.

## Обновление 2026-08-13

Мастера продолжают пользоваться Telegram через VPN. Добавлен канал `telegram` (ADR 005) как один из вариантов свитчера — не единственный и не обязательный.
