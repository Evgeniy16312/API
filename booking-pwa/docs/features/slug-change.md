## Зачем

Мастер может заменить нечитаемый адрес `/m/...` на понятный без перерегистрации.

## Пользовательский сценарий

1. Настройки → поле «Адрес страницы»
2. Вводит `anna-manikur` → Сохранить
3. QR и ссылка ведут на `/m/anna-manikur`
4. Старый slug отдаёт 404

## API

| Метод | Путь | Auth | Описание |
|-------|------|------|----------|
| PATCH | `/api/masters/me` | Bearer/cookie | поле `slug` |

Ошибки: `400` невалидный slug, `409` занят.
