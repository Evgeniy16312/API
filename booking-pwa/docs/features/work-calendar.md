## Зачем

Мастер отмечает, в какие дни и часы принимает; клиент в календаре выбирает день и видит свободные слоты.

## Сценарий

1. Мастер → `/app/schedule` («Календарь» в меню)
2. Включает дни недели + часы, длину слота
3. В месячном календаре смотрит превью слотов
4. Клиент на `/m/[slug]` выбирает услугу → календарь рабочих дней → время

## API

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/slots?slug=&service_id=` | список рабочих дат (`dates`) |
| GET | `/api/slots?slug=&service_id=&date=` | слоты на день |
| PATCH | `/api/masters/me` | `work_schedule`, `slot_duration` |

## UI

- Публичная запись: календарь вместо горизонтального скролла дат
