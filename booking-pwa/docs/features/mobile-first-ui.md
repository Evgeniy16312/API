## Зачем

Почти все мастера ведут кабинет с телефона. Интерфейс должен быть одной рукой: крупные тапы, нижняя навигация, новые записи сразу на главной, ссылка клиенту — через «Поделиться».

## Что хочет пользователь (спрос)

Мастер бьюти/барбер/маникюр:

1. **Не пропустить запись** — список новых сверху, не настройки мессенджеров.
2. **Быстро отдать ссылку** — WhatsApp / Telegram / QR в салоне, без копирования URL пальцем.
3. **Подтвердить одним тапом** — кнопка ≥ 48px, не мелкие чипы.
4. **Не зумить форму** — поля 16px (iOS), safe-area под чёлку и home indicator.
5. **Доверять «своему»** — тёплый салонный фон, не корпоративный синий SaaS.

Клиент на публичной `/m/[slug]`: крупный герой мастера, услуга с ценой, календарь с днями ≥ 44px, слоты сеткой.

## UI

- Токены: `src/app/globals.css` (`--background #f4f0ea`, `--accent #c4a574`, кнопки `min-height: 3rem`)
- Лендинг `/` — sticky CTA «Создать страницу»
- Кабинет `/app` — приветствие, новые записи, QR + share, плитки без MAX/VK
- Нав: `BottomNav` 4.25rem + `env(safe-area-inset-bottom)`, SVG-иконки
- Публичная запись: `BookingFlow` тёмный шапка, `slot-btn`
- `data-testid` форм не менялись (login/register/booking/billing)
