## Зачем

Клиент видит, где мастер принимает. Без платных карт Google.

## Решение (бесплатно)

- Карта: **Leaflet + OpenStreetMap** (без API-ключа)
- Поиск адреса: **Nominatim** через наш прокси `/api/geo/search`

## Сценарий

1. Настройки → «Где принимаете» → ввести адрес → «Найти» → выбрать результат
2. Сохранить (пишет `address`, `lat`, `lng`)
3. На `/m/[slug]` блок «Как добраться» с картой

## API / данные

- Колонки `masters.lat`, `masters.lng`
- `GET /api/geo/search?q=`
- `PATCH /api/masters/me` с `lat`/`lng`

## Ограничения

Nominatim: не долбить запросами (поиск по кнопке, не на каждый keystroke).
