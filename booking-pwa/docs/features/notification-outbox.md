## Зачем

Не терять уведомления при сбое MAX/VK; не блокировать создание записи.

## Как

- Таблица `notification_outbox`
- После записи — enqueue MAX/VK + напоминания мастеру (24ч / 2ч)
- `flushOutbox()` сразу после записи + `POST /api/cron/flush` (ключ `CRON_SECRET` / `ADMIN_SETUP_KEY`)
