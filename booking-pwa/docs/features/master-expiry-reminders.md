## Зачем

Мастер заранее знает, что доступ заканчивается, и успевает оплатить (перевод / позже ЮKassa).

## Сценарий

Cron `/api/cron/flush` (каждые 15 мин на VPS):

1. Синхронизирует статусы подписок  
2. Если до конца trial/`paid_until` осталось **3, 2 или 1 календарный день** — письмо на `notify_email`  
3. Дедуп: один раз на пару «мастер + дней_до_конца + дата окончания»

## API

Ответ flush:

```json
{ "master_expiry_alerts": { "candidates": 1, "sent": 1, "skipped_dup": 0, "skipped_no_email": 0, "failed": 0 } }
```
