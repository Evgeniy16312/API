# Чекпоинт тестирования (остановка)

Проверьте локально перед деплоем.

```bash
cd booking-pwa
npm run dev
# другой терминал:
npm run test:api
```

## Сценарий мастера (5–10 мин)

1. http://localhost:3000/app/register — создать мастера  
2. Услуги → добавить услугу с ценой  
3. Календарь → рабочие дни + сохранить  
4. Настройки → фото, адрес на карте (Найти), сохранить  
5. Скопировать ссылку/QR с главной → открыть `/m/slug` на телефоне или втором окне  

## Сценарий клиента

1. Портфолио / карта / услуги видны  
2. Запись: услуга → календарь дня → слот → имя/телефон  
3. В панели мастера запись в списке  

## Уведомления (без продакшен HTTPS)

- Outbox создаётся при записи (даже без токенов MAX/VK)  
- Flush: `curl -X POST http://localhost:3000/api/cron/flush -H "x-admin-key: $ADMIN_SETUP_KEY"`  
- Реальная доставка MAX/VK — после деплоя с HTTPS  

## Что дальше после вашего ОКОК

Пришлите: **домен** или **IP VPS** → настраиваем Docker + Caddy + MAX webhook → пилот.
