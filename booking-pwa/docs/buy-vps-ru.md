# Покупка VPS + домена (актуальный выбор)

## Решение

| | Было (REG Cloud) | **Берём сейчас** |
|--|------------------|------------------|
| Площадка VPS | REG.RU Cloud ~748 ₽ за 1 ГБ + IP | **[FirstVDS](https://firstvds.ru/)** |
| Почему | IP платный отдельно | **IP уже в тарифе**, дешевле, легко апгрейд |
| Тариф | HP C1-M1 ~748 ₽ | **«Старт» ~519 ₽/мес** |
| Конфиг | 1 CPU · 1 ГБ · 10 ГБ | **1 CPU · 2 ГБ · 40 ГБ SSD** + **1 IPv4** |
| Запасной вариант | — | «Прогрев» ~299 ₽ (1 ГБ · 15 ГБ) если очень жёстко по деньгам |
| Домен | REG.RU `.ru` | Можно купить на REG.RU / Timeweb — **не обязан быть там же, где VPS** |

Цены сверяйте на сайте в день оплаты: https://firstvds.ru/

## Сравнение «почему не REG Cloud»

| | REG (ваш расчёт) | FirstVDS Старт |
|--|------------------|----------------|
| RAM | 1 ГБ | **2 ГБ** |
| Диск | 10 ГБ | **40 ГБ** |
| Публичный IP | +187 ₽ | **включён** |
| Итого ≈ | **748 ₽** | **~519 ₽** |

Для Docker + Next **2 ГБ** важнее «быстрого» HP-процессора.

Альтернатива ещё дешевле: **[VDSina](https://vdsina.ru/)** — от ~150 ₽ (1 ГБ), 2 ГБ ~600 ₽; IP уточняйте в корзине (~+40 ₽). FirstVDS чуть привычнее для «долго и стабильно».

## Шаги покупки

### 1. Домен (если ещё нет)
- https://www.reg.ru/ или https://timeweb.com/ru/services/domains/  
- `.ru` на 1 год  
- DNS потом укажете на IP FirstVDS  

### 2. VPS на FirstVDS
1. https://firstvds.ru/ → регистрация  
2. Заказать VDS → локация **Москва**  
3. Тариф **«Старт»** (2 ГБ) — рекомендуем  
4. ОС: **Ubuntu 24.04** (или 22.04)  
5. Панель ISPmanager — **не нужна**, откажитесь если предлагают платно  
6. Бэкап платный — на старте можно без  
7. Оплатить  

### 3. DNS
В кабинете домена A-записи:
- `@` → IP сервера FirstVDS  
- `www` → тот же IP  

### 4. Написать агенту
```
Провайдер: FirstVDS
Тариф: Старт
IP: ...
Домен: ...
ОС: Ubuntu 24.04
```

Дальше: Docker + HTTPS + деплой МояЗапись (`docs/deploy.md`).
